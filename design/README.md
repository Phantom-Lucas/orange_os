## 3. 一分钟摘要

Orange/64 从 MBR 和二级 Loader 启动，在 QEMU x86-64 上进入长模式与高半区内核，
建立 Ring 3 用户态、进程/线程调度、36 个系统调用、COW 与匿名 `mmap`、同步与 IPC、
ATA PIO LBA48、分层 MyFS、TTY/三控制台、图形 framebuffer/VGA 回退、libc、Shell 和
20 余个用户程序。项目不是把书中 32 位源码直接移植，而是沿用 Orange'S 的“由启动到
完整系统、以消息和服务组织设备/文件系统”的学习路线，在 x86-64 环境重新组织实现。

当前源码约 19,135 行（`boot/`、`kernel/`、`usr/`、`tools/` 的 C/头文件/汇编/链接脚本，
含空行和注释；该数字只说明工程规模，不代表个人原创行数）。最终固定种子完整回归
16/16 通过；同步压力用例另以 100 轮 × 每线程 20,000 次通过。
